# memory-growth-log

The unchanged C logger extracted from the pinned built bridge encodes ten retained native memory metadata inventories growing from one to five objects. Five complete frames and five unchanged-body reuse frames reconstruct every metadata byte, including new identities and bounded names. Array payload/cache compactness is separately tested by memory_growth_compact.py. This replay does not claim a new HDL execution, destruction/reuse, or operational board cost.

Dense bytes: 3648; compact bytes: 1975. These are measured evidence sizes for this fixture, not operational growth bounds. Three replay/tamper tests cover this report.
