# memory-growth-compact

Ten newly executed native dense/compact pairs reconstruct every array byte while four memories and their lazy caches are allocated. Includes high X bits, declared ranges, complete word-cache parent/word ownership and original/disabled continuation. Does not qualify destruction, reuse, metadata delta logging or continuous board observation.

Dense bytes: 8619; compact bytes: 5788. These are measured evidence sizes for this fixture, not operational growth bounds. Three replay/tamper tests cover this report.
