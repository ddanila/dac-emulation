# Integrated unsupported parameter recovery

Binary, real and string diagnostic modes each create an unsupported subclass at 5 and 6 microseconds. Direct parameter and full snapshot construction refuse both the live unsupported object and the stale scope entry after actual native virtual deletion, with zero output and unchanged logger cache pointers and sequence counters. Detachment restores the entire original state exactly. These diagnostic objects are actually freed and have no compiled references.

Each mode retains six snapshots at three selected boundaries, with all observer checks and normal compiled bindings applied without removal of diagnostic objects from comparison copies. All 27,578 waveform samples across 31 signals through 20 microseconds and all firmware records match the original reference. Each mode has four matching bus edges after the second restoration. Four full review/rejection tests pass; source and bridge checks were also run before capture. Exact-build native recovery and native-layout evidence are bound by the reviewer.

This qualifies selected recovery controls, not continuous observation, full graph teardown, allocator address reuse, or dangling-handle safety. Boundary ordinals count logged selections, not every simulator hook. Existing queued campaigns and full-repeat deferral are unchanged.
