# Integrated board recovery and native teardown

Binary, real and string recovery modes each complete the full 20-us board run. All 27,578 waveform samples across 31 signals, all firmware records, initialized models and four post-restoration bus edges match the original reference. Six selected complete snapshots per mode retain all preceding observer and compiled-binding checks. Unsupported parameter allocation, live/stale refusal and exact restoration occur at 5 and 6 us.

At native shutdown each mode destroys all 56 compiled parameters and three memories, bound to the final observed native addresses. Both roots and eight measured observer registration containers end empty: 32 initialized scopes, 32 scope metadata records, 1,932 attached object/ID/type entries, 317 ports, 317 port slots and 875 port bits are cleared. All seven scope-dependent inventories then refuse during VPI unload with -1 and zero output. The complete teardown log, capture receipts, same-build native regressions, runtime identities, generated bridge and test output are retained. Five full review/rejection tests pass.

ASAN is loaded into the host and instruments the candidate Icarus runtime, bundled system module and unload probe. Host/bridge code is not fully instrumented. Fixed VPI loader tables are excluded from global instrumentation; leak detection and Valgrind annotations are disabled. This qualifies the retained integrated controls and measured teardown, not every runtime registry, custom-pool accesses, arbitrary dangling handles, runtime reuse or continuous observation. Existing queued campaigns and full-repeat deferral remain unchanged.
